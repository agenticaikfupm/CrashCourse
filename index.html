About the course

What you will learn

This crash course is offered by the Agentic AI @ KFUPM community. It assumes no prior knowledge of Agentic AI.

Learning objectives

  • Explain how AI evolved from GANs and Transformers to agents and Physical AI.
  • Describe the components of an agent and how they work together.
  • Choose a suitable design pattern for a given task.
  • Explain how always-on agents work in the background and stay under human control.
  • Connect agents to tools and data with MCP and decision APIs.
  • Build and trace an end-to-end agent loop in Python.
  • Prototype workflows with no-code platforms such as n8n.
  • Build agents in Python with SDKs and reach many models through OpenRouter.
  • Apply guardrails, evaluation, monitoring, and human oversight.

Who it is for

University students, researchers, faculty, and practitioners from any discipline who want a practical understanding of AI agents.

Prerequisites

  • Basic Python: variables, functions, lists, and dictionaries.
  • A web browser. Most examples run in the page; others open in free Google Colab.
  • No paid API keys are required. Module 9 uses a free OpenRouter key.

How to use this site

Work through the modules in order or jump to what you need. Each module opens with a short narrated overview (in English or Arabic) and ends with three questions to check your understanding. Your progress is saved on your device.

Course structure

Ten modules, from foundations to governance

Modules 1 and 2 build the vocabulary. Modules 3 to 9 show how to design, connect, and run agents, from patterns and always-on agents to no-code and code-based workflows. Module 10 covers how to deploy them responsibly.

Expected outcomes

By the end you will be able to...

  • Read an agent architecture diagram and name each part.
  • Sketch a workflow for a real task and justify the pattern you chose.
  • Write a small agent loop in Python with tools, memory, and feedback.
  • Expose a capability to agents through an MCP server or a decision API.
  • Choose an agent SDK and switch between free and commercial models.
  • Propose guardrails, an evaluation plan, and an approval policy for an agent.
