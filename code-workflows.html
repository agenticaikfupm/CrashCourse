Module 9

Code-based Agentic Workflows

When a workflow outgrows a visual canvas, you build it in code. Agent SDKs give you agents, tools, and the agent loop as ready-made building blocks, and model gateways let the same code use commercial, open, and free models.

About 50 minutes10 Python examplesIntermediate

Why build agents in code?

Module 8 showed visual platforms that are great for prototypes and app-to-app automation. Code becomes the better choice when you need custom logic, automated tests, version control, careful cost and performance tuning, or deployment inside your own systems. You do not have to start from scratch: agent SDKs (software development kits) handle the repetitive parts.

What an SDK does for you

Before using a real SDK, see its core ideas in plain Python: a @tool decorator that turns a function into a schema, an Agent, a runner loop, a handoff to a specialist agent, an input guardrail, and a trace. No API key needed: a scripted stand-in plays the model.

How to choose

Start with the SDK closest to the model provider you use most, or with a provider-neutral one (LangChain, Pydantic AI, smolagents) if you want to switch models freely. Choose CrewAI or AutoGen when your design is naturally a team of agents. All of them change quickly, so check the official docs for the current API.

One key, many models: OpenRouter and Commonstack

Each model provider has its own account, key, and API. A model gateway puts many providers behind one OpenAI-compatible API, so you can compare and switch models by changing a single string.

Keep your API key secret

Store keys in Colab Secrets or an environment variable, never in a notebook you share or a file you commit to GitHub. If a key leaks, delete it in the provider's dashboard and create a new one. Set a spending limit on keys used for commercial models.

About these examples

They follow each SDK's official documentation at the time of writing and were checked to install, configure the agent and tool, and reach OpenRouter. Run each notebook in its own Colab runtime: some SDKs need different versions of the same package (for example, CrewAI and the OpenAI Agents SDK require different versions of openai). SDKs and free model lists change often; if an example breaks, compare it with the linked docs.
