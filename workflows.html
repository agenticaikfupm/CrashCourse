Module 6

Agentic AI Workflows

An agent is a loop, not a single answer. It perceives, reasons, plans, and acts, then uses the outcome as feedback to do better on the next cycle.

The loop

Perception → Reasoning → Planning → Action → Feedback and learning. Solid arrows show the main flow of information. Dashed arrows show how outcomes flow back to improve perception, reasoning, or planning. Select a stage to see what goes in and what comes out.

Information flow, stage by stage

Inputs and outputs of each workflow stage
StageInputOutputTypical techniques
PerceptionMessages, images, sensor data, tool resultsStructured observationParsing, vision and speech models, validation

Two speeds of learning

Inside one task, feedback changes the next step (retry, replan, update memory). Across many tasks, collected feedback can improve the system itself: better prompts, tools, rules, or a fine-tuned model. The second kind should go through evaluation before deployment.

End-to-end example: a campus shuttle dispatcher

This program runs the whole loop for five time steps. Each stage is a small function so you can match the code to the diagram.

Inputs

  • Riders waiting at three stops, for five time steps (simulated sensors)
  • A target: nobody waits more than 8 minutes

Outputs

  • A dispatch plan for each step
  • Measured wait times
  • The learned congestion threshold

Execution steps

  1. perceive() cleans the readings
  2. reason() finds congested stops
  3. plan() orders and limits dispatches
  4. act() simulates the outcome
  5. learn() updates the threshold

Run it and watch the threshold drop from 20 to 12 after the agent misses its target twice. That is feedback changing future reasoning.

Illustrative simulation

The rider numbers and wait-time formula are invented for teaching. In a real deployment, the reasoning step could be an LLM or a decision API, and the action step would call a real dispatch system.

Try these changes

  • Set max_wait_target to 6.0. How many cycles does it take to adapt?
  • Allow three extra shuttles in plan(). What happens to the worst wait?
